# Visão Geral do Cliente (Client Overview)

> **Público:** CSMs, GMs e gestores  
> **Onde encontrar:** Menu lateral → **Portfolio** → **Client Overview**  
> **Última atualização:** 2026-08

---

## O que é o Client Overview?

O **Client Overview** é a visão consolidada 360° de um cliente específico. Ele integra em um único lugar três fontes de dados Cisco:

| Seção | O que exibe |
|---|---|
| **Cisco EA License Usage** | Consumo de licenças do Enterprise Agreement |
| **Cisco Smart Account (SA)** | Inventário de ativos e licenças na Smart Account |
| **Cisco True Forward** | Análise de consumo excedente ao contrato |

É a tela mais completa para entender a situação contratual e de consumo de um cliente antes de uma reunião de revisão ou renovação.

---

## Como usar o Client Overview

### Passo 1 — Selecionar o cliente

No topo da página, use o **dropdown com busca** para localizar e selecionar o cliente desejado. Comece digitando o nome e as opções aparecerão automaticamente.

### Passo 2 — Navegar pelas seções

Após selecionar o cliente, os dados carregam automaticamente nas três seções/abas. Navegue entre elas para acessar cada visão.

---

## Seção 1: Cisco EA License Usage

Exibe o consumo de licenças do **Enterprise Agreement** do cliente:

- **Gráficos** de consumo por produto/suite
- **Tabelas** com detalhamento de licenças por SKU
- Comparativo entre o que foi **contratado** e o que está sendo **consumido**

> Use esta seção para identificar se o cliente está subutilizando licenças (oportunidade de engajamento) ou se está próximo do limite (risco de True Forward).

---

## Seção 2: Cisco Smart Account (SA)

Exibe o inventário de licenças na **Smart Account Cisco** do cliente:

- Lista de todos os produtos e licenças registrados na Smart Account
- Status de ativação de cada licença
- Comparativo com o que foi contratado

> A Smart Account é o repositório central da Cisco onde todas as licenças digitais do cliente ficam registradas.

---

## Seção 3: Cisco True Forward

Exibe a análise de **consumo excedente** em relação ao contrato:

- Identificação de produtos em **overage** (consumo acima do contratado)
- Estimativa do valor de True Forward a ser cobrado na renovação
- Gráficos interativos de evolução do consumo

### O que fazer ao identificar overage?

Se o True Forward mostrar consumo excedente:

1. Registre a situação no módulo **Tasks** criando uma tarefa do tipo "Consumo Excedente: CISCO EA"
2. Converse com o cliente sobre possibilidade de ajuste do contrato
3. Analise se o consumo excedente é justificado ou se há licenças sendo usadas indevidamente
4. Acompanhe a evolução nas próximas semanas

---

## Dicas de uso

- Use o **Client Overview** como preparação para reuniões de QBR (Quarterly Business Review) com o cliente — ele reúne toda a informação contratual em um só lugar.
- Verifique as **três seções** para ter uma visão completa: às vezes o EA está normal, mas a Smart Account revela licenças não ativadas.
- O **True Forward** é o dado mais crítico — clientes com overage precisam de tratativa proativa antes da renovação.
- Os dados são atualizados via importações automáticas. Se os dados parecerem desatualizados, entre em contato com a equipe de sustentação.
