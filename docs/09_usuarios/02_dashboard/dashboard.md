# Dashboard — Página Inicial

> **Público:** Todos os usuários  
> **Onde encontrar:** Menu lateral → **Dashboard** (ícone de casa)  
> **Última atualização:** 2026-08

---

## O que é o Dashboard?

O **Dashboard** é a primeira tela que aparece após o login. Ele apresenta um resumo do estado atual das tarefas e atividades do seu dia, funcionando como um ponto de partida para o trabalho diário.

Não é necessária nenhuma configuração para ver o Dashboard — ele carrega automaticamente as informações relevantes para o seu usuário.

---

## O que aparece no Dashboard?

O Dashboard exibe informações organizadas em dois painéis:

### Painel Principal (esquerda)

Apresenta um resumo geral da saúde do portfólio de tarefas:

- **Tarefas para hoje** — tarefas com follow-up ou vencimento agendado para o dia atual
- **Alertas e pendências** — itens que requerem atenção imediata
- **Indicadores de status** — visão rápida do estado do portfólio de adoção

### Painel do Dia (direita)

Exibe informações específicas do dia corrente:

- **Follow-ups de hoje** — lista de tarefas que precisam de contato hoje
- **Atividades vencidas** — atividades cujo prazo já passou e ainda estão abertas
- **Próximos vencimentos** — tarefas e atividades com prazo nos próximos dias

---

## Como usar o Dashboard

O Dashboard é uma tela de **leitura** — você não edita informações diretamente nele, mas pode:

1. **Clicar em uma tarefa** para abrir os detalhes completos
2. **Usar os atalhos** para navegar rapidamente para os módulos mais usados
3. **Verificar alertas** para priorizar seu trabalho do dia

---

## Dicas de uso do Dashboard

- **Comece sempre pelo Dashboard** ao abrir o portal: ele mostra tudo que precisa de atenção imediata.
- Para ver detalhes completos de uma tarefa listada, clique sobre ela.
- As informações do Dashboard são atualizadas automaticamente ao carregar a página. Para recarregar, pressione **F5** ou use o botão de atualização do navegador.
