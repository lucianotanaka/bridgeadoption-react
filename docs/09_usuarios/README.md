## O que é o Bridge Adoption?

O **Bridge Adoption** é o portal web interno da NTT Data para gestão da adoção tecnológica de clientes Cisco. Ele centraliza o acompanhamento de tarefas, projetos, contratos, licenças e incentivos Cisco em um único lugar, permitindo que toda a equipe acompanhe o progresso das contas em tempo real.
