# CSM Account — Portfólio de Contas por CSM

> **Público:** CSMs, GMs e gestores  
> **Onde encontrar:** Menu lateral → **Adoption** → **CSM Account**  
> **Última atualização:** 2026-08

---

## O que é o CSM Account?

O módulo **CSM Account** exibe o **portfólio de contas por CSM** — mostra quais clientes cada Customer Success Manager é responsável, com informações de AM (Account Manager), EA (Enterprise Agreement) e tipo de atendimento.

É útil para gestores que precisam ter uma visão rápida da carteira de cada profissional, e para os próprios CSMs consultarem sua base de clientes.

---

## O que você vê na tela

### Filtros disponíveis

| Filtro | Descrição |
|---|---|
| **CSM** | Filtrar por Customer Success Manager |
| **Cliente** | Nome do cliente |
| **AM** | Account Manager responsável |
| **EA** | Filtrar clientes com (Yes) ou sem (No) Enterprise Agreement |
| **Type** | Tipo de atendimento |

Todos os filtros são de **seleção múltipla**. Para limpar todos de uma vez, clique em **Clear all filters**.

### A tabela de contas

A tabela exibe todas as contas com as seguintes colunas:

| Coluna | Descrição |
|---|---|
| **Cliente** | Nome da empresa cliente |
| **CSM** | Customer Success Manager responsável |
| **AM** | Account Manager |
| **EA** | Possui Enterprise Agreement? (Yes/No) |
| **Type** | Tipo de atendimento |

É possível **ordenar** a tabela clicando no cabeçalho de qualquer coluna.

A tabela é **paginada** — selecione quantas linhas ver por página no seletor de paginação.

---

## Tipos de atendimento

O campo **Type** indica o nível de atenção dedicado a cada conta:

| Tipo | Cor | Significado |
|---|---|---|
| **HIGH TOUCH** | 🔴 Vermelho + negrito | Conta estratégica — atenção máxima |
| **SCALE TOUCH** | 🟡 Amarelo | Atenção moderada — escala balanceada |
| **DIGITAL TOUCH** | 🔵 Azul | Atendimento principalmente digital |
| **CUSTOMER** | 🟢 Verde | Cliente padrão |

Use o filtro **Type** para segmentar sua análise por nível de atenção.

---

## Ordenando a tabela

Clique no **cabeçalho de qualquer coluna** para ordenar a tabela por aquele critério. Clique novamente para inverter a ordem (crescente/decrescente).

---

## Dicas de uso

- Use o filtro **CSM** para ver toda a carteira de um profissional específico em uma análise de desempenho.
- Use o filtro **Type = HIGH TOUCH** para focar nas contas estratégicas que exigem maior atenção.
- Combine os filtros **AM + CSM** para entender como as carteiras se distribuem entre os times de AM e CSM.
- Use o filtro **EA = Yes** para identificar rapidamente quais clientes têm Enterprise Agreement ativo.
