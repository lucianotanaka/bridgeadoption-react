# Rebate e Oportunidades

> **Público:** CSMs, GMs e gestores  
> **Onde encontrar:** Menu lateral → **Adoption** → **Rebate**  
> **Última atualização:** 2026-08

---

## O que é o módulo Rebate?

O módulo **Rebate** centraliza o acompanhamento dos **incentivos financeiros Cisco** — tanto do programa **SIP** (Solution Incentive Program) quanto do **LCI** (Life Cycle Incentive) — além do pipeline de oportunidades relacionadas ao **Cisco Enterprise Agreement**.

Ele oferece uma visão financeira consolidada dos incentivos disponíveis, aprovados e em pipeline.

---

## KPIs exibidos

No topo da página você encontra os principais indicadores:

| KPI | O que significa |
|---|---|
| **LCI Aprovados** | Valor total de incentivos LCI aprovados pela Cisco |
| **LCI Jornada** | Valor total de incentivos LCI em jornada (em andamento) |
| **Tarefas de Incentivo** | Número de tarefas ativas vinculadas a incentivos |
| **Oportunidades SIP** | Número de oportunidades ativas no programa SIP |
| **Cisco EA** | Valor relacionado ao Enterprise Agreement |

## O que você vê na tela

### Gráficos de status

Os gráficos exibem a distribuição dos incentivos por status:

- Proporção de incentivos **aprovados**, **em andamento**, **aguardando** e **perdidos**
- Evolução temporal dos incentivos no período

### Tabelas de oportunidades

As tabelas detalham cada oportunidade de rebate/incentivo com:

- Cliente e solução
- Programa (SIP ou LCI)
- Valor potencial e valor aprovado
- Status atual
- Data de elegibilidade / vencimento
- Tarefas vinculadas

## Os programas de incentivo Cisco

### SIP — Solution Incentive Program

O **SIP** é um programa de incentivo da Cisco voltado para projetos de implantação de soluções específicas. Os incentivos são aprovados após a conclusão e validação do projeto pela Cisco.

| Status | Significado |
|---|---|
| **Registrada** | Oportunidade cadastrada no programa |
| **Em Aprovação** | Enviada à Cisco para análise |
| **Aprovada** | Incentivo confirmado pela Cisco |
| **Perdida** | Oportunidade não aprovada ou vencida |

### LCI — Life Cycle Incentive

O **LCI** remunera a NTT pela condução do cliente nas etapas do ciclo de vida das soluções Cisco. Os incentivos são validados estágio a estágio.

> Para detalhes sobre os estágios LCI, consulte: [Cisco LCI](./cisco_lci.md)

---

## Conexão com as Tarefas

As **Tarefas de Incentivo** são tarefas no módulo Tasks criadas especificamente para rastrear atividades que geram incentivos Cisco. O KPI "Tarefas de Incentivo" contabiliza essas tarefas ativas.

Para criar ou acompanhar uma tarefa de incentivo:
1. Acesse o módulo **Tasks**
2. Crie uma nova tarefa selecionando o tipo de incentivo adequado
3. Vincule à solução e ao cliente correto

---

## Dicas de uso

- Acompanhe o KPI **LCI Jornada** semanalmente — ele representa valor em potencial que ainda precisa de ações para ser aprovado.
- Oportunidades **SIP** próximas do vencimento exigem atenção imediata — verifique a data de elegibilidade na tabela.
- Use os gráficos em apresentações gerenciais para mostrar o retorno financeiro das atividades de adoção.
- Cruce os dados do Rebate com o **Team Target** para avaliar o impacto financeiro do atingimento de metas.
