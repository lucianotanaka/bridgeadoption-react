# LCI Status — Elegibilidade por Cliente e Solução

> **Público:** CSMs, GMs e gestores  
> **Onde encontrar:** Menu lateral → **Adoption** → **LCI Status**  
> **Última atualização:** 2026-08

---

## O que é o LCI Status?

O módulo **LCI Status** exibe a **elegibilidade de clientes e soluções para o programa Cisco LCI** (Life Cycle Incentive). Ele responde à pergunta: *"Quais clientes e soluções são elegíveis para receber incentivos LCI?"*

O módulo apresenta duas visões complementares:

| Aba | O que exibe |
|---|---|
| **Eligible Status** | Clientes e soluções elegíveis ao LCI, com status de elegibilidade |
| **Solution vs Project** | Análise de soluções LCI associadas a projetos específicos |

---

## Aba Eligible Status

### O que você vê

A tabela exibe por cliente e solução:

- **Nome do cliente**
- **Solução Cisco** (ex: DNA, Webex, SecureX)
- **Track LCI** — trilha do programa de incentivo
- **Status de elegibilidade** — se o cliente/solução está elegível para o incentivo
- **Informações complementares** de contrato e vigência

### Filtros disponíveis

| Filtro | Descrição |
|---|---|
| **Cliente** | Filtrar por cliente específico |
| **Solução** | Filtrar por solução Cisco |
| **Status** | Filtrar por status de elegibilidade |

### O que significa "Elegível"?

Um cliente/solução é **elegível** para o LCI quando cumpre os requisitos definidos pela Cisco para aquela trilha de incentivo — geralmente relacionados a ter um contrato ativo, estar dentro do período de elegibilidade e ter atividades de adoção em andamento ou concluídas.

---

## Aba Solution vs Project

### O que você vê

Esta aba mostra a **relação entre soluções LCI e os projetos vinculados** a cada cliente. Útil para verificar se as soluções elegíveis estão corretamente associadas a projetos de adoção.

A tabela exibe:

- Cliente
- Solução
- Projeto vinculado (se existir)
- Status do projeto
- Status de elegibilidade LCI

### Por que isso importa?

Para ativar certos estágios do LCI, é necessário que a atividade de adoção esteja vinculada a um projeto formal. Esta aba ajuda a identificar soluções elegíveis que ainda **não têm projeto vinculado** — uma lacuna que pode impedir a aprovação do incentivo.

---

## Conexão com o módulo Tasks

Quando uma tarefa é movida para **IN PROGRESS** na aba **LCI Viability** (módulo Tasks), ela precisa ser vinculada a um projeto. O LCI Status é o complemento dessa visão — mostrando quais soluções e clientes já estão elegíveis e se há projetos associados.

> Para gerenciar tarefas LCI e vincular projetos, consulte: [Criar e Gerenciar Tarefas](../03_tarefas/gerenciar_tarefas.md).

---

## Dicas de uso

- Use o **Eligible Status** para identificar oportunidades LCI que ainda não estão sendo exploradas.
- Use o **Solution vs Project** para garantir que todas as soluções elegíveis têm projetos vinculados — sem isso, o incentivo pode não ser aprovado.
- Combine o LCI Status com o **Cisco LCI** para ter uma visão completa: de um lado a elegibilidade, do outro o desempenho.
- Revise o LCI Status no início de cada trimestre para identificar novas oportunidades de incentivo.
