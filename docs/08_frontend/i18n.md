## 1. Idiomas suportados

| Código | Idioma | Arquivo |
|---|---|---|
| `pt` | Português (padrão) | `frontend/src/i18n/locales/pt.json` |
| `en` | Inglês | `frontend/src/i18n/locales/en.json` |
| `es` | Espanhol | `frontend/src/i18n/locales/es.json` |

O idioma padrão é `pt`. A detecção automática segue a ordem: `localStorage` → `navigator.language` → fallback `pt`.

---

## 2. Configuração (`i18n/index.ts`)

```typescript
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import LanguageDetector from "i18next-browser-languagedetector";
import pt from "./locales/pt.json";
import en from "./locales/en.json";
import es from "./locales/es.json";

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      pt: { translation: pt },
      en: { translation: en },
      es: { translation: es },
    },
    fallbackLng: "pt",
    interpolation: { escapeValue: false },
    detection: {
      order: ["localStorage", "navigator"],
      caches: ["localStorage"],
      lookupLocalStorage: "i18nextLng",
      convertDetectedLanguage: (lng) => {
        // Normaliza pt-BR → pt, en-US → en, es-ES → es
        if (lng.startsWith("pt")) return "pt";
        if (lng.startsWith("en")) return "en";
        if (lng.startsWith("es")) return "es";
        return "pt";
      },
    },
  });
```

## 3. Uso nos componentes

### Básico

```typescript
import { useTranslation } from "react-i18next";

function MeuComponente() {
  const { t } = useTranslation();
  
  return (
    <div>
      <h1>{t("task.title")}</h1>
      <button>{t("common.save")}</button>
      <p>{t("errors.generic")}</p>
    </div>
  );
}
```

### Com interpolação

```typescript
// No JSON: "showing": "Exibindo {{from}}–{{to}} de {{total}}"
t("common.showing", { from: 1, to: 15, total: 150 })
// → "Exibindo 1–15 de 150"
```

### Trocar idioma programaticamente

```typescript
import { useTranslation } from "react-i18next";

const { i18n } = useTranslation();

// Trocar idioma e salvar no banco
i18n.changeLanguage("en");
apiClient.put("/auth/language", { language: "en" });
```

## 5. Sincronização com o banco

O idioma preferido do usuário é salvo em `tbUser.user_language`:
- Banco armazena: `pt-BR`, `en-US`, `es-ES`
- Frontend usa: `pt`, `en`, `es`
- Conversão automática no `useAuth.ts` via `normalizeLanguage()`

### Fluxo completo

```
1. Login → backend retorna language="pt-BR"
2. useAuth.ts: normalizeLanguage("pt-BR") → "pt"
3. i18n.changeLanguage("pt") → aplica português
4. Usuário clica em "EN" no header
5. i18n.changeLanguage("en")
6. PUT /api/auth/language { language: "en" } → salva no banco
7. Próximo login → banco retorna "en-US" → normalizado para "en"
```

## 7. Convenções

- Chaves em **camelCase**: `loginButton`, `noTasks`, `clearFilters`
- Hierarquia máxima de **2 níveis**: `adoption.forecast.title` (3 níveis máx.)
- Strings técnicas sem tradução: termos como "Cisco LCI", "CSM", "EA" **não são traduzidos**
- Textos de UI genéricos: sempre em `common.*`
- Mensagens de erro: sempre em `errors.*`

## 8. Troubleshooting

| Problema | Causa | Solução |
|---|---|---|
| Texto não traduz | Chave não existe no JSON | Adicionar chave nos 3 idiomas |
| Exibe a chave (ex: `task.title`) | Arquivo JSON com erro de sintaxe | Validar JSON no editor |
| Idioma não muda | `i18nextLng` inválido no localStorage | Limpar localStorage e relogar |
| Novo idioma não persiste | `PUT /api/auth/language` não chamado | Verificar fluxo de troca de idioma |
